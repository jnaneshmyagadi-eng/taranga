# TARANGA

**India Creates. World Connects.**

Watch. Create. Belong.

India-born global video + creator + community platform.

## Stack

- Next.js 16 + TypeScript + Tailwind CSS 4
- Supabase (Auth, Postgres, Realtime, Storage)

## Setup

```bash
npm install
cp .env.example .env.local
# Set Supabase URL + keys
# Apply supabase/schema.sql then migrations in order
npm run dev
```
